## 🎨 UI Guidelines & References

This Figma design serves as the primary visual and structural reference for building the Bite Flutter application UI components:

1. **Color Palette & Theme**: Emerald/green accent primary palette, neutral light/dark surface colors, soft shadows, rounded corners.
2. **Typography**: Clean sans-serif hierarchy matching `GoogleFonts.inter`.
3. **Card & Layout Components**: Modern rounded cards for daily macro tracking, food items, search bars, and meal category chips.
4. **Navigation**: Clean bottom bar and smooth screen transitions.
